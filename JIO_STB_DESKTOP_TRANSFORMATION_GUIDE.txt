1. CRITICAL PREREQUISITES & GOTCHAS
================================================================================
Before running any commands, understand these three hard technical constraints:

1. ARCHITECTURE IS 32-BIT ONLY (armeabi-v7a):
   Despite having a 64-bit capable SoC, JioOS runs a 32-bit ARM userland 
   (`ro.product.cpu.abi = armeabi-v7a`). Downloading 64-bit (arm64-v8a) APKs will 
   result in `INSTALL_FAILED_NO_MATCHING_ABIS`. Always use 32-bit or universal APKs.

2. DO NOT USE OUTDATED ADB BINARIES (v1.0.32):
   Old ADB builds (often bundled in older driver packs) fail the modern Android 11 
   RSA authentication handshake, perpetually showing the device as `unauthorized`. 
   Always use modern Google Android SDK Platform-Tools (version 30+ / 35.0.2).

3. TV REMOTE VS. DESKTOP INPUT:
   TV remotes rely on Leanback DPAD directional focus. Desktop environments 
   (Smart Dock, Taskbar, Firefox) rely on pointer MotionEvents. Connect a USB 
   mouse/keyboard or use a 2.4GHz wireless mouse dongle for navigation.

2. PHASE 1: ADB CONNECTIVITY & RESOLVING "UNAUTHORIZED" BUG
================================================================================
1. Find the Jio STB IP address:
   On the TV screen, go to Settings -> Network & Internet -> Connected Wi-Fi -> IP address.
   (Example target: 192.168.31.157).

2. Connect over ADB from your host workstation:
   adb connect <JIO_STB_IP>:5555
   adb devices -l

3. If it shows "unauthorized":
   - Ensure you are using modern platform-tools adb (`adb version` must show 1.0.41 / v30+).
   - Check the TV screen for the "Allow USB debugging?" dialog. Check "Always allow" and click OK.

4. Verify CPU architecture and OS:
   adb -s <JIO_STB_IP>:5555 shell getprop ro.build.version.release
   # Output must return: 11
   adb -s <JIO_STB_IP>:5555 shell getprop ro.product.cpu.abi
   # Output must return: armeabi-v7a

3. PHASE 2: DISPLAY DENSITY (DPI) & SYSTEM FREEFORM OVERRIDES
================================================================================
The stock 320 DPI makes icons and windows giant. Setting it to 200 DPI transforms 
the 1080p output into a crisp, native PC monitor resolution.

1. Inject Global Freeform & Multi-Window Flags:
   adb -s <JIO_STB_IP>:5555 shell settings put global enable_freeform_support 1
   adb -s <JIO_STB_IP>:5555 shell settings put global force_resizable_activities 1
   adb -s <JIO_STB_IP>:5555 shell settings put global enable_non_resizable_multi_window 1
   adb -s <JIO_STB_IP>:5555 shell settings put global development_settings_enabled 1

2. Apply Desktop Display Density:
   adb -s <JIO_STB_IP>:5555 shell wm density 200

3. Reboot STB to Initialize WindowManagerService:
   adb -s <JIO_STB_IP>:5555 reboot
   # Wait 40 seconds, then reconnect:
   adb connect <JIO_STB_IP>:5555

4. Verify Freeform Execution (--windowingMode 5):
   adb -s <JIO_STB_IP>:5555 shell am start -n com.android.tv.settings/.MainSettings --windowingMode 5
   adb -s <JIO_STB_IP>:5555 shell "dumpsys activity top | grep windowingMode"
   # Verification: Must output "mWindowingMode=freeform".

4. PHASE 3: SIDELOADING & CONFIGURING ANDROID DESKTOP SHELL
================================================================================
We use Smart Dock (Windows-like dock and start menu) and Taskbar.

1. Download Desktop Shell APKs on Host:
   Taskbar 6.2.2 Universal:
   curl -L -o taskbar.apk "https://github.com/farmerbb/Taskbar/releases/download/207/Taskbar-6.2.2.apk"
   Smart Dock 1.15.0 Universal:
   curl -L -o smartdock.apk "https://f-droid.org/repo/cu.axel.smartdock_1150.apk"

2. Install to Jio STB:
   adb -s <JIO_STB_IP>:5555 install -r taskbar.apk
   adb -s <JIO_STB_IP>:5555 install -r smartdock.apk

3. Grant Elevated Privileges & AppOps Overlays:
   # Taskbar
   adb -s <JIO_STB_IP>:5555 shell pm grant com.farmerbb.taskbar android.permission.WRITE_SECURE_SETTINGS
   adb -s <JIO_STB_IP>:5555 shell pm grant com.farmerbb.taskbar android.permission.PACKAGE_USAGE_STATS
   adb -s <JIO_STB_IP>:5555 shell appops set com.farmerbb.taskbar SYSTEM_ALERT_WINDOW allow
   adb -s <JIO_STB_IP>:5555 shell appops set com.farmerbb.taskbar GET_USAGE_STATS allow
   adb -s <JIO_STB_IP>:5555 shell cmd deviceidle whitelist +com.farmerbb.taskbar

   # Smart Dock
   adb -s <JIO_STB_IP>:5555 shell pm grant cu.axel.smartdock android.permission.WRITE_SECURE_SETTINGS
   adb -s <JIO_STB_IP>:5555 shell pm grant cu.axel.smartdock android.permission.PACKAGE_USAGE_STATS
   adb -s <JIO_STB_IP>:5555 shell appops set cu.axel.smartdock SYSTEM_ALERT_WINDOW allow
   adb -s <JIO_STB_IP>:5555 shell appops set cu.axel.smartdock GET_USAGE_STATS allow
   adb -s <JIO_STB_IP>:5555 shell appops set cu.axel.smartdock MANAGE_EXTERNAL_STORAGE allow
   adb -s <JIO_STB_IP>:5555 shell cmd deviceidle whitelist +cu.axel.smartdock

4. Activate Accessibility Dock & Notification Listeners:
   adb -s <JIO_STB_IP>:5555 shell settings put secure enabled_accessibility_services cu.axel.smartdock/cu.axel.smartdock.services.DockService
   adb -s <JIO_STB_IP>:5555 shell settings put secure accessibility_enabled 1
   adb -s <JIO_STB_IP>:5555 shell cmd notification allow_listener cu.axel.smartdock/cu.axel.smartdock.services.NotificationService

3. Push the Automated Debian Bootstrap Script:
   Create `init_linux_desktop.sh` locally:
   ------------------------------------------------------------------------------

   pkg update -y && pkg upgrade -y
   pkg install x11-repo proot-distro tigervnc pulseaudio -y
   proot-distro install debian
   proot-distro login debian -- bash -c "apt update && apt install -y xfce4 xfce4-terminal firefox-esr dbus-x11"
   mkdir -p ~/.vnc
   cat << 'VNC_EOF' > ~/.vnc/xstartup
   #!/data/data/com.termux/files/usr/bin/bash
   export DISPLAY=:1
   proot-distro login debian --shared-tmp -- /bin/bash -c "export DISPLAY=:1; service dbus start; startxfce4"
   VNC_EOF
   chmod +x ~/.vnc/xstartup
   vncserver -geometry 1920x1080 -localhost no :1
